INTRODUCING C AND C++ — HISTORY, PURPOSE, AND DIFFERENCES

C
C is a general-purpose programming language strongly associated with procedural programming, systems software, and efficient implementation. Dennis Ritchie developed C at Bell Labs during the early 1970s, influenced by B and BCPL; C became important in Unix development. C has standardized language versions and is widely used in operating systems, embedded software, libraries, and infrastructure.

C++
C++ is a general-purpose, multi-paradigm programming language developed by Bjarne Stroustrup. Work on 'C with Classes' began in 1979; the language was named C++ in 1983. It supports procedural, object-oriented and generic programming, alongside abstractions for resource management and large systems.

RELATIONSHIP
C++ grew out of C, and the languages share much syntax, but they have different rules, standard libraries and compilation modes. Not every valid C program is valid C++, and not every C++ feature exists in C.

FIRST C PROGRAM
#include <stdio.h>

int main(void) {
    printf("Hello, C!\n");
    return 0;
}

FIRST C++ PROGRAM
#include <iostream>

int main() {
    std::cout << "Hello, C++!\n";
    return 0;
}

CODE ANATOMY
# introduces a preprocessing directive.
include asks the preprocessor to include a header's declarations.
<stdio.h> is the C standard I/O header.
<iostream> provides C++ stream declarations.
int names the return type of main.
main names the program entry function.
(void) explicitly specifies no parameters in C.
() specifies no parameters in C++.
{ and } delimit the function body.
printf calls a formatted output function.
std::cout refers to the standard output stream.
<< inserts data into that stream.
"..." is a string literal.
\n represents a newline character.
; ends a statement.
return 0; reports successful termination; reaching the end of main also returns zero in standard C and C++.

WHY PLACEMENT MATTERS
A preprocessor directive begins with # outside the function in these examples; a statement such as printf belongs inside a function body. A header is included to make declarations available. Parentheses after main are part of the function declarator. Braces determine the body and scope. Indentation improves readability but does not replace braces.
