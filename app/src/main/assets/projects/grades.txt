Student results

SPECIFICATION
Parse command → validate unique positive ID and finite score 0–100 → update collection → calculate average or lookup → save validated records → validate complete input before load replacement.

ALGORITHM / TEXT FLOWCHART
Start → read bounded input → validate → apply one domain operation → report → repeat or exit.
Invalid input → diagnostic/rejection → no invalid state update.

MILESTONES
1. Add a student record.
2. Reject duplicates and invalid scores.
3. Search by ID and calculate average.
4. Save through a temporary file.
5. Validate load into a separate collection before replacing current state.

CODE ANATOMY
The illustrative pass threshold is 50, not an institutional GPA policy. structs group IDs and scores. The array capacity is 100; count is the number of initialized records. A separate incoming array makes failed loads non-destructive. Division occurs only when count is positive.

INPUT CONTRACT
These bounded console exercises accept small, representable numbers and whitespace-separated commands. Use the commands in the test. Text tokens cannot contain spaces. Numeric scanf conversion is not a hardened parser for arbitrarily huge values: replace it with strtol/strtod plus end-pointer/range checking as a robustness extension. The reference is procedural code valid as both C11 and C++17; it is not an idiomatic object-oriented C++ solution.
