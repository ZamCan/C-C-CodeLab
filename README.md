# CodeLab C & C++

Offline-first Android programming academy for C and C++.

## Planned modules
- Native offline compiler and execution sandbox (not yet integrated)
- 10 C and 10 C++ foundational lessons
- Worked mathematical and real-world programming problems
- Quizzes, automatic assessment and guided corrections
- Phone-friendly syntax-highlighted code editor
- Optional AdMob advertising when online

## Engineering status
The host Linux compiler proof of concept has been tested separately. Android APK compilation, on-device native compilation, and AdMob integration have **not** yet been verified. The full source prototype is being prepared for import.

## Academic approach
Explain each syntax element and why it is used, demonstrate small programs, extend to practical projects, and offer feedback after student attempts.
