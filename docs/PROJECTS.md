# Five post-course guided projects

All projects are learning exercises that execute in Code Studio; they do not create Android APKs. Each has a written specification, flowchart or pseudocode, sample I/O, starter files, progressive milestones, reference solution, tests, debugging exercises, and an optional labeled static UI preview.

| Project | C implementation | C++ implementation | Key skills |
| --- | --- | --- | --- |
| Calculator | Functions + stdio + math.h | Functions + iostream + cmath | arithmetic, input validation, division by zero |
| Login demonstration | structs + string handling | classes + string | input, state, authentication concepts; never imply production security |
| Student grades | arrays/structs/files | vector/classes/files | records, GPA policy, validation |
| ATM simulator | structs + menu | classes + vector | transactions, invariants, error handling |
| Library system | structs + files | classes + vector/maps | searching, borrowing, return dates, record persistence |

Learning progression: explore specification → inspect expected interface → understand code → implement incrementally → compile/run locally → compare real output to tests → reflect. Static mockups are separate from live terminal output.
